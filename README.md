# MARVEL · Кинетический архив

> **Живая версия:** https://ajlex-wf.github.io/marvel-sculptures/
> Деплой — GitHub Pages через GitHub Actions (`.github/workflows/pages.yml`), каждый push в `main` публикует сайт заново.

Интерактивный сайт-каталог **динамических скульптур супергероев Marvel** — вымышленной
экспозиции, где каждая композиция «оживает»: вращающиеся сердечники, орбитальные кольца
и световые разряды.

Вся графика — оригинальная векторная (SVG), сгенерированная кодом. Никаких внешних
изображений и сторонних библиотек.

---

## Запуск

Откройте `index.html` в браузере — сборка не требуется.

Для локального сервера (например, чтобы проверить шрифты из Google Fonts):

```bash
npx serve .
# или
python -m http.server 8000
```

## Что внутри

**Генератор кинетических скульптур** (`app.js → buildSculpture`)
Фигура собирается из параметров позы: углы плеч, локтей, бёдер и коленей задаются
в данных, а из них вычисляются координаты суставов. Над скелетом накладываются:

- торс с V-образным переходом талии, нагрудные пластины и пояс;
- голова: шлемы, рога, маски и открытые лица (с тоном кожи и волос);
- реквизит: щит, Мьёльнир, дуги, паутина, арбалет, скипетр, магический круг, рой, фотонные сгустки;
- плащ, обтекающий фигуру и уходящий влево;
- кинетика: орбитальные кольца, узлы-спутники, световые разряды, следы движения;
- постамент, который автоматически встаёт под стопы фигуры.

Каждая скульптура описана объектом в `sculptures.js`:

```js
{
  id: "iron-man",
  name: "Железный Человек",
  colors: ["#b5122a", "#f2a63b", "#7fd8ff"],   // материал, блик, энергия
  pose: { lean: 9, armA: [124, 12], armB: [-42, 16], legA: [24, 12], legB: [-32, -16] },
  prop: "reactor",
  stats: { power: 92, speed: 88, tech: 99, endurance: 84 }
}
```

Углы задаются в градусах: `0°` — вниз, `90°` — вправо, `180°` — вверх.
Угол в скобках — изгиб в суставе.

**Интерактивность**

| Элемент | Поведение |
|---|---|
| Фильтры коллекции | 6 категорий, плавная перерисовка сетки |
| Первый экран | 3D-ядро на canvas: икосаэдр со светом, 5 орбитальных колец, 220 частиц пыли. Сцена наклоняется за курсором, пыль притягивается и завихривается вокруг него, механизм разгоняется при наведении на ядро |
| Карточка → «Рассмотреть» | модальное окно со спецификацией и статистикой |
| Поворотный круг | слайдер вращает скульптуру по оси Y, есть автовращение |
| Клавиатура | `←` `→` — переключение скульптур, `Esc` — закрыть |
| Кнопка «Движение» | останавливает/возобновляет все анимации сразу (включая 3D-ядро) |
| Форма записи | клиентская валидация, подтверждение с датой сеанса |
| Счётчики и появление | запускаются при попадании в зону видимости |

**Доступность и производительность**

- Lighthouse: 100 / 100 / 100 (доступность, лучшие практики, SEO);
- поддержка `prefers-reduced-motion`;
- шрифты подключены с системным запасным вариантом;
- отсутствие зависимостей и тяжёлых ресурсов.

## Переключение композиций

Чтобы добавить скульптуру, достаточно дописать объект в `window.SCULPTURES`
(`assets/js/sculptures.js`) — карточка, фильтры и модальное окно подхватят его сами.
Новый `prop` добавляется одной веткой `case` в функции `buildProp`.
